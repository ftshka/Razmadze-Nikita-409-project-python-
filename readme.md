# Python project
## Marketplace
Программа написана на питоне с использованием библиотеки tkinter и оператора with для работы с файлами.
На домашней странице можно зарегестрироваться в качестве продавца или покупателя, потом из этой же страницы войти.
Продавцы могут добавлять товары и указывать стоимость
Покупатели могут искать товары по названию и покупать их, введя во второе окно ценник.
В программе осуществлено свободное перемещение между окнами.
