# Python project
## Marketplace description
Программа написана на питоне с использованием библиотеки tkinter и оператора with для работы с файлами.
На домашней странице можно зарегестрироваться в качестве продавца или покупателя, потом из этой же страницы войти.
Продавцы могут добавлять товары и указывать стоимость
Покупатели могут искать товары по названию и покупать их, введя во второе окно ценник.
В программе осуществлено свободное перемещение между окнами.

## Инструкция
1) Установить все файлы в пустую папку на компьютере
2) Зайти в файл marketplace.py
3) изменить путь к файлу в строках: 79, 122, 168, 171, 221, 244, 258, 261, 314
   '**/home/ftshka/python/Razmadze-Nikita-409-project-python-/**data_customers.txt' ---> '**ваш путь к файлу**data_customers.txt'
4) запускаем файл marketplace.py
5) регестрируетесь(просто ввести пароль)
6) входите в аккаунт(если продавец, то продавец, если покупатель, то покупатель)
7) добавляете товар, если вы продавец и покупаете или ищете если вы покупательgit
